# Route Registry & SEO Notes

| Route | File Path | Rendering Mode | Description & SEO Rules |
|---|---|---|---|
| `/` | `app/page.tsx` | SSR (`force-dynamic`) | Homepage. Main hero slider, featured categories, flash sales, mega deals, bottom SEO content block. Canonical: `/`. Schema: `Organization`, `WebSite`. |
| `/category/[category]` | `app/category/[category]/page.tsx` | SSR (`force-dynamic`) | Live CMS category catalog (`getCmsAdapter()`). Supports URL-driven filters (`price`, `brand`, `availability`, `socket`, `ramType`, `formFactor`, `storageInterface`, `q`), sort, pagination, `BrandNavStrip`, `/category/all` (`"All Products"` global search target), and `?builder=1&slot=...` (`prefilter=1` automatic pre-filter guard). Filtered/sorted/paginated URLs (`hasNonCanonicalFilterParams`) and empty unfiltered categories (`total === 0`) emit `canonical` pointing to clean `/category/[category]` and `noindex,follow`. Schema: `BreadcrumbList` (via `Breadcrumbs`), `ItemList`. Exactly one `<h1>`. |
| `/category/[category]/[brand]` | `app/category/[category]/[brand]/page.tsx` | SSR (`force-dynamic`) | Live CMS brand-in-category catalog with `lockedBrandSlug` (route segment `brand` always overrides any manual `?brand=` query param; brand checkbox group hidden in `FilterSidebar`). Marked `noindex,follow` when filtered/sorted/paginated, when `brand === "other"`, or when total brand products `< 3` (`!matchedBrand?.isIndexable`). Canonicalizes to clean `/category/[category]/[brand]`. Schema: `BreadcrumbList` (via `Breadcrumbs`), `ItemList`. Exactly one `<h1>`. |
| `/product/[slug]` | `app/product/[slug]/page.tsx` | SSR (`force-dynamic`) | Live CMS product detail via `getProductBySlug(slug)` (`notFound()` if missing). Supports `?preview=1` when `isAdminAuthenticated()` is true via `CustomCmsAdapter.getProductPreviewBySlug(slug)` (renders sticky `PREVIEW MODE` banner + `noindex,nofollow` metadata; normal/unauthenticated requests remain publish-only). Priority `SafeProductImage` (`next/image`) hero or SVG fallback, BDT `price`/`salePrice`/`"Call for price"` fallback, availability & warranty badges, normalized specification `<table>` with `Explicit`/`Parsed`/`Override`/`CMS Raw` source badges, `"Add to PC Builder"` link mapping all 12 `componentType` values (including `other` -> `"others"` slot), and up to 4 related same-category CMS products. Schema: `Product`, `BreadcrumbList` (via `Breadcrumbs`). Exactly one `<h1>`. |
| `/pc-builder` | `app/pc-builder/page.tsx` | SSR (`force-dynamic`) + Client Hydration | 12-slot PC Builder (`PcBuilderClient`). SSR resolves `?add=<slug>&slot=<slotId>` and `?share=<encoded>` via `getCmsAdapter()` and computes per-slot attribute coverage (`evaluateCategoryHealth` with DEVIATION D6 unrounded `< 60%` status guard); client hydrates/persists `pc_builder_state` in `localStorage` with cross-tab sync, soft-navigation query key sync, live pricing/wattage/compatibility, `"Could not verify"` manual toggles, hydration-safe `@media print` summary, and shareable URLs. Query-parameterized URLs (`/pc-builder?*`) are disallowed in `app/robots.ts`. |
| `/compare` | `app/compare/page.tsx` | SSR Shell + Client Hydration | SSR shell (`Breadcrumbs`, single `<h1>`, `"Browse Catalog"` link) wrapping client-hydrated `<CompareTable />` (`localStorage` `pc_compare_items` via `CompareProvider`; up to 4 same-category items, diff highlighting, `"Show differences only"` toggle, remove/clear). Marked `noIndex: true` (`noindex,follow`) and disallowed in `robots.ts`. |
| `/admin` | `app/admin/page.tsx` | Dynamic / Client-Hydrated | WordPress-style Custom CMS Admin & Live Preview Dashboard (`AdminCmsApp`). Protected by `CMS_ADMIN_TOKEN` (via `pc_cms_admin` httpOnly HMAC cookie). Manages products (draft/publish, duplicate, quick-edit, structured spec builder, live storefront preview), media library, categories, and JSON snapshot backup/reset. Marked `noindex,nofollow` and disallowed in `robots.ts`. |
| `/data-health` | `app/data-health/page.tsx` | SSR (Dynamic) | Quality audit dashboard for catalog attributes. Requires explicit `DATA_HEALTH_TOKEN` via `?token=` when `NODE_ENV === "production"` (no fallback token; denied if unset). In non-production environments falls back to `demo-health-token-secret` (and allows local `development` access when unset). Marked `noindex,nofollow` and disallowed in `robots.ts`. |
| `/contact` | `app/contact/page.tsx` | Static (SSG) | Contact page (`canonicalPath: "/contact"`). Renders `Breadcrumbs`, single `<h1>`, 3 support info cards (`16793`, `webteam@startechbd.com`, Corporate Office), accessible Zod-validated `<ContactForm />` submitting to `/api/contact`, and a 5-showroom `Our Branch Locations` directory grid. |
| `/privacy-policy` | `app/privacy-policy/page.tsx` | Static (SSG) | Privacy Policy (`canonicalPath: "/privacy-policy"`). Renders `Breadcrumbs`, single `<h1>`, anchored sections (`#information-collected`, `#cookies`, `#third-party`, `#data-security`, `#your-rights`), browser storage keys table (`pc_compare_items`, `pc_builder_state`, `pc_cookie_consent`, `_ga, _ga_*`), embedded `<CookieSettingsButton />`, and cross-links to `/contact` & `/terms`. |
| `/terms` | `app/terms/page.tsx` | Static (SSG) | Terms & Conditions (`canonicalPath: "/terms"`). Renders `Breadcrumbs`, single `<h1>`, quick-jump anchor pills, and 7 `scroll-mt-24` sections matching `Footer` anchor targets (`#pricing`, `#warranty`, `#delivery`, `#refund`, `#emi`, `#star-points`, `#pc-builder`), plus cross-links to `/privacy-policy` & `/contact`. |
| `/robots.txt` | `app/robots.ts` | Dynamic | Disallows `/admin`, `/admin/*`, `/data-health`, `/data-health/*`, `/pc-builder?*`, `/cart`, `/checkout`, `/compare`, `/api/*`. |
| `/sitemap.xml` | `app/sitemap.ts` | Dynamic (`revalidate = 3600`) | Lists homepage, `/pc-builder`, `/contact`, `/privacy-policy`, `/terms`, categories with >= 1 product (including populated top-level parent nav categories `component`, `power`, `accessories`, `gaming`, `server-storage` without duplicates or synthetic `all`), indexable brand pages (>= `INDEX_MIN_PRODUCTS`, excluding `"other"`), and all active products. |
| `/api/contact` | `app/api/contact/route.ts` | Dynamic API | `POST`-only endpoint delegating to `handleContactRequest()` (`lib/contact/handler.ts`): per-IP rate limiting (`5` req / `10` min -> `429` + `Retry-After`), Zod `contactSchema` validation + silent `honeypot` rejection (`400`), and email dispatch (`RESEND_API_KEY` -> `SMTP_HOST` -> `demo` fallback returning `200`, or `502` on transport failure). |
| `/api/cms/auth` | `app/api/cms/auth/route.ts` | Dynamic API | `GET` returns `{ authenticated, configured, isProduction }`; `POST { token }` validates against `CMS_ADMIN_TOKEN`/`DATA_HEALTH_TOKEN` and sets `HttpOnly`, `SameSite=Lax` `pc_cms_admin` HMAC cookie; `DELETE` clears cookie. |
| `/api/cms/products` | `app/api/cms/products/route.ts` | Dynamic API | Auth-guarded (`401` when unauthenticated). `GET (?status=all\|publish\|draft&q=&category=)` returns `{ products, total }` with raw records + normalized `Product`; `POST` creates/upserts a product (`201`). |
| `/api/cms/products/[id]` | `app/api/cms/products/[id]/route.ts` | Dynamic API | Auth-guarded (`401`). `GET` fetches product; `PATCH` partially updates product; `DELETE` deletes product; `POST { action: "duplicate" }` clones product as `draft` (`201`). |
| `/api/cms/categories` | `app/api/cms/categories/route.ts` | Dynamic API | Auth-guarded (`401`). `GET` lists categories with `productCount` & `publishedCount`; `POST` creates/updates category; `DELETE ?slug=` removes category. |
| `/api/cms/media` | `app/api/cms/media/route.ts` | Dynamic API | Auth-guarded (`401`). `GET` lists uploaded media metadata; `POST` accepts multipart `file` or JSON `{ filename, mimeType, dataBase64 }` (PNG/JPEG/WebP/AVIF/GIF, `<= 2 MB` -> `413` if oversized, `400` if invalid) and returns `201 { media }` with `/api/cms/media/<id>`. |
| `/api/cms/media/[id]` | `app/api/cms/media/[id]/route.ts` | Dynamic API | **Public** `GET` serves binary image bytes with `Content-Type` and `Cache-Control: public, max-age=31536000, immutable` (for storefront & PDP rendering); auth-guarded `DELETE` deletes media item. |
| `/api/cms/seed` | `app/api/cms/seed/route.ts` | Dynamic API | Auth-guarded (`401`). `GET` exports full `CustomCmsSnapshot` JSON backup; `POST { action: "reset" \| "import", snapshot? }` resets catalog to initial 32-product demo seed or imports a JSON snapshot. |

## Global Layout, Redirects & Headers

- **`app/layout.tsx`**: Injects dynamic `NEXT_PUBLIC_GSC_VERIFICATION` into `metadata.verification.google` via `constructMetadata()`, mounts `<CookieConsent />`, and mounts consent-gated `<GoogleAnalytics measurementId={process.env.NEXT_PUBLIC_GA_ID} />`.
- **`next.config.js` & `data/redirects.json`**: Emits 12 permanent `statusCode: 301` redirects (`/old-category/laptops`, `/build-pc`, `/cpus`, `/gpus`, `/motherboards`, `/contact-us`, `/privacy`, `/terms-and-conditions`, `/offers`, `/deals`, `/account`, `/cart`) via `redirects()`, and sets `Referrer-Policy: strict-origin-when-cross-origin` and `Permissions-Policy: geolocation=(), camera=(), microphone=()` across `/(.*)` via `headers()`.
